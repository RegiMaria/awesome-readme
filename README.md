## 🗂️ Mapeamento de Elementos Interativos

Para você saber exatamente onde encontrar cada recurso nos arquivos de exemplo, confira nossa referência rápida:

| Elemento | Onde ficou |
| :--- | :--- |
| ✨ **Texto digitando (Typing SVG)** | Logo abaixo do nome, no lugar do subtítulo fixo |
| 👀 **Contador de visitas** | Junto das badges do topo |
| 🕒 **Badge de fuso horário** | Junto das badges do topo |
| 🌊 **Divisor com onda** | Substituindo o primeiro `---`, entre o cabeçalho e "Sobre mim" |
| ✅ **Checklist / Roadmap 2026** | Logo após "Minha Jornada" |
| ❓ **Seção recolhível (FAQ)** | Entre "Principais Projetos" e "Passo a passo" |
| 🎵 **Spotify "tocando agora"** | Logo após "Vídeos" |

## 💡 Como usar

1. **Escolha um Tema:** Acesse a tabela acima e abra o modelo desejado.
2. **Copie o Código:** Abra o arquivo `.md` no modo *Raw* e copie todo o conteúdo.
3. **Cole no Seu Perfil:** Cole no README
